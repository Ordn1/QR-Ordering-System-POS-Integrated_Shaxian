# IT 22/L Capstone 1
## Software Prototyping Rubric (Excellent: 96–100 Points Only)

| Criteria | Weight | Excellent (96–100) |
|----------|:------:|--------------------|
| **1. Systems Design & Architecture** | **20%** | Well-designed database tables with complete entities, attributes, proper data types, primary/foreign keys, and constraints. IPO model clearly demonstrates information flow. Systems architecture accurately represents all requirements and supports efficient operations. |
| **2. Data Integrity & Relationships** | **15%** | All table relationships correctly established with appropriate primary/foreign keys. Referential integrity rules fully implemented. Proper constraints and minimal data redundancy through normalization. |
| **3. UI/Database Mapping & Implementation** | **20%** | All UI input fields, forms, and displayed data accurately mapped to database tables/columns. Complete data flow between UI and database clearly demonstrated. All core functionalities properly integrated. |
| **4. UI Layout, Organization & UX** | **20%** | Well-structured, organized interface with proper component placement. Intuitive navigation and clear user flow. Consistent alignment, spacing, and grouping. Provides smooth interaction and allows users to complete tasks efficiently. |
| **5. Oral Presentation & Prototype Demonstration** | **25%** | Prototype walkthrough is exceptionally clear, well-paced, and easy to follow. Technical explanations are precise and appropriate. Student confidently articulates design decisions and demonstrates strong command of the system. Verbal communication is engaging and well-organized. |

---

## Student Outcome D (Legal & Ethical Principles)

Students are expected to demonstrate awareness of legal and ethical principles in computing practice through appropriate data handling, privacy considerations in system design, and ethical documentation practices. This expectation applies across all criteria.

**Total Weight:** **100%**
