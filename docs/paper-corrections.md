## 4. Objectives and modules — mostly resolved

**1.3.2.4 — now genuinely met, except one clause.** Rules are generated by
**mlxtend** from real transaction history: `backend/jobs/apriori.py`, run as
`python -m jobs.apriori` or from the dashboard's "Run Apriori job" button, at
`min_support = 0.15`, `min_lift = 1.05`, segmented by `session_type`. A clean seed
yields 12 standard / 12 priority / 11 group rules.

Still unbuilt: *"incorporate a returning customer's previous-order history when an
optional account or senior/PWD identification is provided."* There is no
`customers` table. **Either strike that clause or mark it as future work.**

**1.3.2.5 — now implemented as an integration layer with a simulated register.**
`app/services/pos.py` builds a validated payload from a settled transaction and
transmits it over the local network; `app/routers/pos.py` exposes the bridge, the
transmission log, and the register inbox. Transmission fires automatically when
the cashier confirms cash. Payloads are idempotent — a retry returns the same
receipt number rather than double-posting.

**§2.2.3.1.13 needs one honest edit.** It currently says the system transmits "to
the restaurant's local point-of-sale infrastructure database". Say instead that the
integration layer transmits to a POS endpoint on the local network, and that the
prototype targets a simulated register because the partner's POS schema is
undocumented. That is both true and stronger — the layer is real and repointing it
at a live register is a change of endpoint, not of design.

**Table 3** — the "Local POS Terminal / Existing Register" row should note the
terminal is simulated in the prototype.

**Table 4** — mlxtend is now genuinely in the stack, so that row stands. PayMongo
is still sandbox-only with a simulated success screen, which §1.4 already discloses.

**§2.2.3.1.6 Split Billing / Table 1 "Split Bill"** — the screen exists and shows
real per-share amounts, but attribution is derived rather than tracked per device.
Worth one sentence: shares are reconciled at the counter in the prototype.
